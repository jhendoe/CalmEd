# CalmEd 🌿

CalmEd is a student-focused wellness application designed to help students manage academic stress and maintain better mental well-being.

The application provides simple tools that encourage students to pause, check in with themselves, and practice healthy stress-management habits.

## Features

- 🔐 User Registration and Login
- 📊 Personal Dashboard
- 🧠 Daily Stress Check-In
- 😊 Mood Tracking
- 🌿 Wellness and Relaxation Activities
- ⏱️ Simple Breathing Exercises
- 🔔 Wellness Reminders
- 👤 User Profile
- 🚪 Logout

## Technologies

- C#
- Blazor
- HTML
- CSS

## Purpose

CalmEd aims to provide students with an accessible and simple space where they can monitor their stress levels and practice small wellness activities alongside their academic responsibilities.
